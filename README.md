# -STREAMING-CONTENT-VIEWER-ANALYTICS-DASHBOARD
# ABOUT
  Netflix Data Analysis using Power BI is a media analytics project focused on analyzing Netflix content, customer viewing behavior, subscription plans, ratings, genres, and regional trends. The project uses data cleaning, data modeling, DAX, and interactive dashboards to generate actionable business insights.
# TOOLS
Power BI – Dashboard and data visualization
DAX – Measures, KPIs, and analytical calculations
Power Query – Data cleaning and transformation
Microsoft Excel – Data preprocessing and analysis
Data Modeling – Connecting content and customer datasets
Interactive Visualizations – Charts, maps, KPIs, and slicers
# KEY INSIGHTS
🎬 Identified top-performing movies and TV shows based on watch time.
👥 Analyzed viewer preferences across age groups.
💳 Compared Basic, Standard, and Premium subscription engagement.
🌎 Identified genre popularity and engagement trends across countries.
⭐ Analyzed customer rating distributions across content and genres.
👤 Identified high-value viewers with more than 5,000 watch minutes.
🎭 Evaluated genre performance to support content strategy.
🎥 Analyzed director and cast influence on viewer ratings.
📅 Identified potential optimal content release periods.
🌐 Highlighted opportunities for regional content localization.
